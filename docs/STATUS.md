  `EI.04b.tessellation_independence`. Управляемая плотность сетки STL, если она нужна, - отдельное
  исследование (настройки документа либо конфигурационный файл конвертера), решение за заказчиком.
- **Второе расхождение измерения со справкой (названо).** Признак `IAdditionFormatParam.formatBinary`
  на целевой сборке даёт вид файла, ОБРАТНЫЙ справке: `true` даёт текстовый STL, `false` - двоичный.
  Сервер пишет документированное значение, ОПРЕДЕЛЯЕТ вид файла ПО СОДЕРЖИМОМУ и при расхождении
  записывает противоположное значение; ответ называет запрошенный вид, определённый и фактически
  записанный признак. Подробности - `docs/04_KOMPAS_API_NOTES.md` §4.67.
- **Не выполнено нарядом G3 и названо:** проверка второго семейства параметров (угол вращения

  выдавливании.
