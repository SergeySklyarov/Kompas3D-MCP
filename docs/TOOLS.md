# Инструменты Kompas3D MCP

Полный список инструментов сервера. Схемы аргументов каждого инструмента лежат в
[`schemas/`](../schemas/), подробные контракты описаны в [02_TOOL_CONTRACTS.md](02_TOOL_CONTRACTS.md).
