# Documents (Domain) — решения и измерения

Модуль: `src/KompasMcp.Domain/Documents/`. Здесь — история правок, вынесенная из кода.

## <a id="save-tracking"></a>Собственный учёт сохранённости (05.10.2026)

**Что было.** Предпринималась попытка опираться на грубый геометрический отпечаток модели.

**Что измерено (на самом коде).** Отпечаток последней наблюдаемой ревизии сравнивался с текущим, а
мутация записывала в него СВЕЖЕЕ значение, поэтому «отпечатки равны» получалось ровно в тот момент,
когда модель уже разошлась с файлом. Отпечаток отвечает на другой вопрос — «менял ли модель кто-то
помимо нас».

**Почему учёт собственный.** Документированного признака «документ изменён» у целевой версии нет: в
справке v24 у `ksDocument3D` перечислены все методы и свойства, и среди них нет ни «IsSaved», ни
«Modified» (страницы `ksdocument3d_methods.html`, `ksdocument3d_properties.html`), а в interop
установленной версии такого члена тоже нет. Спрашивать у CAD «сохранён ли документ» нечем, поэтому
состояние ведёт приложение — это логика продукта, а не маршрут SDK.

**Что решено.** Отпечаток используется только для ответа на вопрос «менял ли модель кто-то помимо нас»;
состояние сохранённости ведёт `DocumentSaveTracking` (переходы + таблица решений о закрытии),
проверяемый без КОМПАС.
