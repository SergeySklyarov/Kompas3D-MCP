# KompasMCP 0.1.0 - переменные и материал, эскиз на плоскости по ссылке

Выпуск для КОМПАС-3D v24 x64: детали, сборки, сопряжения, чертежи, переменные и материал детали.
Готовый пакет Windows x64, собирать ничего не нужно.

**Новая схема версий.** С этого выпуска тег - версия продукта `vMAJOR.MINOR.PATCH`, а не имя по
составу. Прежние выпуски (`v24-mechanical-core-v1`, `v24-core-assemblies-mates-v1`,
`v24-core-assemblies-mates-drawings-v1`) содержали ошибки и удалены. Правило - в
[`AGENTS.md`](../../AGENTS.md), раздел «Версии и выпуски».

нет.

## Требования

- Windows x64.
- КОМПАС-3D v24 x64 (проверено на 24.0.0.2799), установленный, лицензированный и зарегистрированный
  для COM у текущего пользователя. Его DLL и interop в пакет не входят.
- .NET 10 Runtime x64 (`Microsoft.NETCore.App 10.x`); подходит и .NET 10 Desktop Runtime x64.
  .NET SDK не нужен.

Установка и подключение: [Codex](../operator-guide/codex-setup.md),
[Claude](../operator-guide/claude-setup.md), [другой клиент](../operator-guide/install.md).

## Что изменилось с v24-core-assemblies-mates-drawings-v1

- **Профиль переменных и материала закрыт.** Плотность читается документированным расчётом МЦХ
  (`ksPart.CalcMassInertiaProperties(ST_MIX_M|ST_MIX_KG).r`), где единицу задаёт аргумент вызова,
  поэтому она приходит в кг/м³ без пересчёта сервером. Назначение материала подтверждается
  перечитыванием плотности тем же маршрутом; масса считается по плотности из модели.
- **Эскиз на плоскости по ссылке.** Форма `plane: { reference }` теперь проходит схему клиента у
  `kompas_create_sketch` и `kompas_set_sketch_plane`. Эскиз «на грани» строится документированно:
  `kompas_create_aux_geometry` (`plane/offset`, `base_face_ref`) даёт плоскость у грани, эскиз
  ставится на неё по ссылке.
- **Версия сервера.** `serverInfo.version` = `0.1.0`; штамп сборок - `0.1.0+<коммит>`.

**Изменения контракта, которые могут потребовать правки клиента:**
- `kompas_get_material`: плотность - поле `density_kg_per_m3` (кг/м³) с `density_unit` и
  `density_route`; прежние `density_raw`, `density_raw_unit_documented`, `density_unit_status`,
  `density_normalized_kg_per_m3` убраны. Старое показание `GetDensity()` осталось диагностикой
  (`get_density_raw_diagnostic`, `get_density_raw_unit_documented`).
- `kompas_set_material`: подтверждение плотности - `read_density_kg_per_m3_after`,
  `density_matches`, `density_tolerance_kg_per_m3`, `density_unit`, `density_route`; прежние
  `read_density_raw_after`, `density_raw_unit_documented`, `density_unit_status`,
  `density_normalized_kg_per_m3`, `density_raw_numeric_matches` убраны.
- `kompas_create_sketch`: `base` и `reference` вместе, ни одного из них, `reference` вместе с
  `offset_mm` и ссылка не на плоскость теперь отвергаются `INVALID_ARGUMENT` - как у
  `kompas_set_sketch_plane`. Раньше `create_sketch` такие запросы молча принимал.

## Чего в выпуске нет

- Эскиз прямо на грани: документированный маршрут принимает опорой плоскость; грань отвергается по
  виду ссылки. Плоскость у грани - см. выше.
- Две одноимённые плоскости одного типа в одном документе как опора эскиза неразличимы: сервер
  отказывает с числом совпадений, а не выбирает.
- Создание и удаление переменных: `kompas_set_variable` меняет существующую внешнюю переменную.
- Массивы компонентов сборки, полная спецификация (BOM), виды сопряжений сверх `mates-minimal-v1`,
  правка компонентов внутри подсборок.
- Спецификации, сборочные чертежи и прочие 2D-документы, кроме чертежей профиля
  `drawings-minimal-v1`.
- Это не весь каталог операций P6: в каталоге 36 семейств, выпуск закрывает пять профилей выше.
- Цифровой подписи у выпуска нет: `SHA256SUMS.txt` проверяет целостность скачанного файла, а не
  личность издателя.

**Известные расхождения, найденные приёмкой:** `kompas_resolve_selection` объявляет поле
`coordinate_space`, но вызов с ним отвергается `INVALID_ARGUMENT`; у сопряжения запрошенное
`alignment: opposite` читается обратно как `closest` (причина не установлена).

## Проверка выпуска

Все прогоны сняты на бинарях этого пакета (собственные сборки совпадают с `release-manifest.json`)
на КОМПАС-3D v24.0.0.2799, 07.10.2026. Пакет собран из закоммиченного исходника, штамп сборок
называет коммит сборки.

- модульные тесты 665/665; сборка Release x64 - 0 ошибок, 0 предупреждений;
- проверка пакета `scripts/verify-delivery.py`: 78 инструментов, схемы на проводе совпадают с
  поставленными и репозиторными, `problems: []`;
- полный живой прогон `scripts/mcp-smoke.py`: **1104/1104**;
- обязательный объём `scripts/acceptance-levels.py`: 78/78 режимов, 36/36 зависимостей, открыто 0;
- клиентская приёмка рабочим MCP-клиентом: **27 сценариев из 27**, включая плотность в кг/м³,
  цепочку «плотность → масса», эскиз на плоскости от грани и отказы формы опоры;
- паспорт поставки: доставка, функциональная приёмка, обязательный объём и клиентская приёмка -
  итог PASS.
