# KompasMCP 0.2.0 - честный контракт выбора граней, выравнивание сопряжений по геометрии

Выпуск для КОМПАС-3D v24 x64: детали, сборки, сопряжения, чертежи, переменные и материал детали.
Готовый пакет Windows x64, собирать ничего не нужно.

## Файлы выпуска

| Файл | Что это |
|---|---|
| `KompasMCP-v0.2.0-win-x64.zip` | готовый сервер: Host, Worker, зависимости, схемы, шаблон конфигурации, `INSTALL.md`, установщик, лицензии |
| `SHA256SUMS.txt` | SHA-256 архива, манифеста и установщика |
| `release-manifest.json` | версия, объём, требования, число и имена инструментов, хеши собственных сборок, коммит сборки |
| `Install-KompasMcp.ps1` | установщик: зависимости, контрольная сумма, распаковка, конфигурация, самопроверка |

Архив «Source code» на странице выпуска GitHub создаёт сам: это исходники, готового сервера в нём
нет.

## Требования

- Windows x64.
- КОМПАС-3D v24 x64 (проверено на 24.0.0.2799), установленный, лицензированный и зарегистрированный
  для COM у текущего пользователя. Его DLL и interop в пакет не входят.
- .NET 10 Runtime x64 (`Microsoft.NETCore.App 10.x`); подходит и .NET 10 Desktop Runtime x64.
  .NET SDK не нужен.

Установка и подключение: [Codex](../operator-guide/codex-setup.md),
[Claude](../operator-guide/claude-setup.md), [другой клиент](../operator-guide/install.md).

подтверждено живым прогоном:

| Профиль | Что закрывает | Режимы | Зависимости |

| `assemblies-minimal-v1` | сборки: вставка, замена, размещение, ссылки на файлы | 7/7 | 5/5 |
| `mates-minimal-v1` | сопряжения: создание, параметр, фиксация, удаление | 6/6 | 5/5 |
| `drawings-minimal-v1` | чертежи: виды из модели, размеры, штамп, техтребования, DXF/DWG | 6/6 | 6/6 |

## Что изменилось с v0.1.0

- **Выравнивание сопряжений проверяется по геометрии.** В 0.1.0 значение `alignment` у
  `kompas_create_mate` записывалось, но не проверялось: ответ сообщал успех, даже когда грани встали
  не так, как просили. Теперь `opposite` и `cooriented` подтверждаются измеренной ориентацией граней
  в координатах сборки: `face_normals_dot` = -1 (навстречу) или +1 (в одну сторону). Не совпало -
  отказ `GEOMETRY_FAILED`. `closest` ориентацию не задаёт: её выбирает КОМПАС, сервер возвращает
  получившуюся.
- **Честный контракт выбора граней.** Из предиката `kompas_resolve_selection` удалено поле
  `coordinate_space`: сервер отвергал любое его значение, а инструмент работает от тела детали и
  другой системы координат не имеет.

**Изменения контракта, которые могут потребовать правки клиента:**
- `kompas_resolve_selection`: поле `predicate.coordinate_space` удалено; вызов с ним отвергается
  схемой как лишнее поле. Нормаль `normal_direction` задаётся в системе координат детали.
- `kompas_create_mate`: ответ дополнен полями `alignment_requested`, `alignment_read` (значение,
  прочитанное у сопряжения, - факт, а не подтверждение) и `face_normals_dot` (ориентация граней в
  координатах сборки; `null` - не запрашивалось или не прочитано).
- `kompas_create_mate`: при явном `opposite`/`cooriented`, если грани встали иначе, - отказ
  `GEOMETRY_FAILED` с `partial_effects=true` (сопряжение уже создано). В 0.1.0 такой вызов возвращал
  успех.

## Чего в выпуске нет

- Выравнивание подтверждается для сопряжений плоских граней. Для граней без единственной нормали
  (цилиндр, конус) ориентация не читается - ответ называет это примечанием
  `alignment_orientation_unverified`; для `perpendicular` знак ориентации смысла не имеет -
  примечание `alignment_value_unconfirmable`.
- Эскиз прямо на грани: опорой эскиза служит плоскость; плоскость у грани строится
  `kompas_create_aux_geometry` (`plane/offset`, `base_face_ref`).
- Создание и удаление переменных: `kompas_set_variable` меняет существующую внешнюю переменную.
- Массивы компонентов сборки, полная спецификация (BOM), виды сопряжений сверх `mates-minimal-v1`,
  правка компонентов внутри подсборок.
- Спецификации, сборочные чертежи и прочие 2D-документы, кроме чертежей профиля
  `drawings-minimal-v1`.
- Это не весь каталог операций P6: в каталоге 36 семейств, выпуск закрывает пять профилей выше.
- Цифровой подписи у выпуска нет: `SHA256SUMS.txt` проверяет целостность скачанного файла, а не
  личность издателя.

**Известные ограничения.** Изредка операция над телом (наблюдалось на вырезе с явной целью и на
скруглениях касательных рёбер) возвращает `GEOMETRY_FAILED`: сервер сам измерил, что операция не
применилась, и модель не портится. Повтор проходит. Причина не установлена.

## Проверка выпуска

Пакет собран из закоммиченного исходника (`b8178dc`), штамп сборок `0.2.0+b8178dc…` называет коммит
сборки. Модульные тесты 704/704; сборка Release x64 - 0 ошибок, 0 предупреждений; проверка пакета
`scripts/verify-delivery.py`: 78 инструментов, схемы на проводе совпадают с поставленными и
репозиторными.
