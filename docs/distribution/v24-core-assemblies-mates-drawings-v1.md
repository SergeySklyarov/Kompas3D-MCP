# KompasMCP v24-core-assemblies-mates-drawings-v1

Выпуск для КОМПАС-3D v24 x64: детали, сборки, сопряжения и чертежи. Готовый пакет Windows x64,
собирать ничего не нужно.

## Файлы выпуска

| Файл | Что это |
|---|---|
| `KompasMCP-v24-core-assemblies-mates-drawings-v1-win-x64.zip` | готовый сервер: Host, Worker, зависимости, схемы, шаблон конфигурации, `INSTALL.md`, установщик, лицензии |
| `SHA256SUMS.txt` | SHA-256 архива, манифеста и установщика |
| `release-manifest.json` | тег, объём, требования, число и имена инструментов, хеши собственных сборок |
| `Install-KompasMcp.ps1` | установщик: зависимости, контрольная сумма, распаковка, конфигурация, самопроверка, регистрация в Codex |

Архив «Source code» на странице выпуска GitHub создаёт сам: это исходники, готового сервера в нём
нет.

## Требования

- Windows x64.
- КОМПАС-3D v24 x64, установленный, лицензированный и зарегистрированный для COM у текущего
  пользователя. Его DLL и interop в пакет не входят.
- .NET 10 Runtime x64 (`Microsoft.NETCore.App 10.x`); подходит и .NET 10 Desktop Runtime x64.
  .NET SDK не нужен. Пакет framework-dependent, поэтому runtime обязателен.

Установка и подключение к Codex: [codex-setup.md](../operator-guide/codex-setup.md).

## Объём

78 инструментов MCP. Четыре профиля выпуска закрыты полностью, пятый открыт:

| Профиль | Что закрывает | Режимы | Зависимости |
|---|---|---|---|
| `mechanical-core-v1` | детали: эскизы, операции, массивы, правка, измерение, STEP, снимок модели | 54/54 | 15/15 |
| `assemblies-minimal-v1` | сборки: вставка, замена, размещение, ссылки на файлы | 7/7 | 5/5 |
| `mates-minimal-v1` | сопряжения: создание, параметр, фиксация, удаление | 6/6 | 5/5 |
| `drawings-minimal-v1` | чертежи: виды из модели, размеры, штамп, техтребования, DXF/DWG | 6/6 | 6/6 |
| `variables-material-minimal-v1` | переменные и материал детали - профиль **открыт** | 3/5 | 4/5 |

Профиль закрыт, когда каждое применимое действие его режимов подтверждено живым прогоном на
КОМПАС-3D v24.0.0.2799. Профиль переменных и материала закрытым не называется: открыто три
действия, все по одной причине - единица чтения плотности не подтверждена документом, поэтому
действие `read` стоит `implemented`, а не `verified`. Инструменты этого профиля в пакете есть.
Измерено `scripts/acceptance-levels.py` 06.10.2026: режимов 76/78, зависимостей 35/36, открыто 3.

## Чего в выпуске нет

- Это не весь каталог операций P6: в каталоге 36 семейств, выпуск закрывает четыре профиля выше.
- Массивы компонентов сборки, полная спецификация (BOM) и виды сопряжений сверх
  `mates-minimal-v1`.
- Спецификации, сборочные чертежи и прочие 2D-документы, кроме чертежей профиля
  `drawings-minimal-v1`.
- Закрытие профиля `variables-material-minimal-v1`: открыто три действия (единица чтения
  плотности).
- Правка компонентов внутри подсборок: они читаются (`kompas_list_components` с `recursive`), но
  адреса для правки у них нет, размещение и замена вложенного компонента отвергаются.
- Цифровой подписи у выпуска нет: `SHA256SUMS.txt` проверяет целостность скачанного файла, а не
  личность издателя.

## Что изменилось с v24-core-assemblies-mates-v1

- **Чертежи** (профиль `drawings-minimal-v1`): группа стандартных ассоциативных видов из модели,
  список видов, размеры - линейный, диаметральный и радиальный, основная надпись с записью и
  перечитыванием ячеек штампа, технические требования, экспорт в DXF/DWG с проверкой выгруженного
  файла.
- **Внешние переменные и материал детали** (профиль `variables-material-minimal-v1`): чтение
  переменных верхнего компонента, присвоение числового значения и выражения, чтение и назначение
  материала с плотностью.
- Ответ записи материала отделяет подтверждённое от неподтверждённого: имя материала и исходы
  вызовов подтверждаются, а физическая плотность помечается `density_unit_status=unconfirmed`, и
  нормированное значение в килограммах на кубический метр не выдаётся.
- Сборка и `dotnet test` приведены к одной платформе x64: правило записано в `AGENTS.md`, решение -
  в `docs/decisions/build.md`.
- Исправления по ревью чертежей: трактовка `IConverter.Convert` приведена к справке v24 (успех -
  только 1), форма выгрузки v24 - ZIP-контейнер, а не текстовый DXF; открыты
  `kompas_set_technical_demand` и режим DRW-06; вывод об отсутствии маршрута правки вида исправлен
  (`IView.Scale` плюс `IDrawingObject.Update`), открыт `kompas_edit_view`.

## Проверка выпуска

Все прогоны сняты на бинарях этого пакета (собственные сборки совпадают с `release-manifest.json`)
на КОМПАС-3D v24.0.0.2799, 06.10.2026:

- модульные тесты 660/660; сборка Release x64 - 0 ошибок, 0 предупреждений;
- проверка пакета `scripts/verify-delivery.py`: 78 инструментов, схемы на проводе совпадают и с
  поставленными, и с репозиторными, `repo_drift: []`, `problems: []`;
- полный живой прогон `scripts/mcp-smoke.py`: **1101/1101**;
- группа чертежей `--drawing-only`: **79/79**;
- группа переменных и материала `--variables-material-only`: **55 PASS / 1 NAMED / 0 FAIL**.
  Единственная `NAMED` - `VM-06.mass.computed_via_measure.read`: плотность для расчёта массы взята из
  ответа `kompas_get_material`, а не из справочника сервера и не из запроса, - то есть цепочку
  «плотность модели, затем масса» выполнить нечем, пока единица чтения плотности не подтверждена
  документом;
- клиентская приёмка рабочим MCP-клиентом на этом выпуске **не запускалась**. На предыдущем выпуске
  она пройдена - 16 сценариев из 16 (Codex CLI, замер 05.10.2026), и на текущий выпуск этот замер не
  переносится.
