# KompasMCP v24-core-assemblies-mates-v1

Выпуск для КОМПАС-3D v24 x64: детали, сборки и сопряжения. Готовый пакет Windows x64, собирать
ничего не нужно.

## Файлы выпуска

| Файл | Что это |
|---|---|
| `KompasMCP-v24-core-assemblies-mates-v1-win-x64.zip` | готовый сервер: Host, Worker, зависимости, схемы, шаблон конфигурации, `INSTALL.md`, установщик, лицензии |
| `SHA256SUMS.txt` | SHA-256 архива, манифеста и установщика |
| `release-manifest.json` | тег, объём, требования, число и имена инструментов, хеши собственных сборок |
| `Install-KompasMcp.ps1` | установщик: зависимости, контрольная сумма, распаковка, конфигурация, самопроверка, регистрация в Codex |

Архив «Source code» на странице выпуска GitHub создаёт сам: это исходники, готового сервера в нём
нет.

## Требования

- Windows x64.
- КОМПАС-3D v24 x64, установленный, лицензированный и зарегистрированный для COM у текущего
  пользователя. Его DLL и interop в пакет не входят.
- .NET 10 Runtime x64 (`Microsoft.NETCore.App 10.x`); подходит и .NET 10 Desktop Runtime x64.
  .NET SDK не нужен. Пакет framework-dependent, поэтому runtime обязателен.

Установка и подключение к Codex: [codex-setup.md](../operator-guide/codex-setup.md).

## Объём

63 инструмента MCP. Три профиля выпуска закрыты полностью:

| Профиль | Что закрывает | Режимы | Зависимости |
|---|---|---|---|
| `mechanical-core-v1` | детали: эскизы, операции, массивы, правка, измерение, STEP, снимок модели | 54/54 | 15/15 |
| `assemblies-minimal-v1` | сборки: вставка, замена, размещение, ссылки на файлы | 7/7 | 5/5 |
| `mates-minimal-v1` | сопряжения: создание, параметр, фиксация, удаление | 6/6 | 5/5 |

Профиль закрыт, когда каждое применимое действие его режимов подтверждено живым прогоном на
КОМПАС-3D v24.0.0.2799.

## Чего в выпуске нет

- Это не весь каталог операций P6: в каталоге 32 семейства, выпуск закрывает три профиля выше.
- Массивы компонентов сборки, полная спецификация (BOM) и виды сопряжений сверх
  `mates-minimal-v1`.
- Чертежи и другие 2D-документы.
- Правка компонентов внутри подсборок: они читаются (`kompas_list_components` с `recursive`), но
  адреса для правки у них нет, размещение и замена вложенного компонента отвергаются.
- Цифровой подписи у выпуска нет: `SHA256SUMS.txt` проверяет целостность скачанного файла, а не
  личность издателя.

## Что изменилось с v24-mechanical-core-v1

- Сборки и сопряжения (профили `assemblies-minimal-v1` и `mates-minimal-v1`).
- Явный захват и передача CAD-сеанса между чатами (`kompas_acquire_session`,
  `kompas_release_session`, `kompas_session_status`).
- Растровый снимок модели в заданной проекции (`kompas_export_image`).
- Исправления по независимой проверке кода: защита от потери несохранённых правок при перезапуске
  Worker, восстановление файла только по политике путей, сверка тождества компонента и сопряжения
  перед мутацией.
- Созданное сопряжение находится и тогда, когда оно сделало недействительным прежнее; число таких
  прежних сопряжений называется в ответе.
- Готовый ZIP с контрольными суммами, манифестом и установщиком для Codex.

## Проверка выпуска

Все прогоны сняты на бинарях этого пакета (собственные сборки совпадают с `release-manifest.json`)
на КОМПАС-3D v24.0.0.2799:

- модульные тесты 527/527;
- проверка пакета `scripts/verify-delivery.py`: 63 инструмента, схемы совпадают с ответом сервера;
- полный живой прогон `scripts/mcp-smoke.py`: 1102/1102. В первом из двух полных прогонов одна
  строка (MANIA.19) не прошла: первое перестроение переоткрытой детали один раз дало другой объём,
  второе вернуло верный. Повтор полного прогона и три прогона группы MANIA эффект не повторили;
- группы сборок 68/68, сопряжений 56/56, снимка модели 44/44;
- клиентская приёмка в Codex CLI: 16 сценариев из 16 (деталь, сохранение и переоткрытие, сборка
  из двух экземпляров, сопряжения, идемпотентность, отрицательные контроли, освобождение сеанса),
  сверена по журналу операций сервера и по файлам на диске;
- установщик: проверка зависимостей, отказ до распаковки при неверной контрольной сумме,
  повторная установка без изменений, сохранность других серверов в `config.toml` Codex.
