# Состояние и планы KompasMCP

[На главную](../README.md)

Целевая версия: КОМПАС-3D v24.0.0.2799 x64. Текущий выпуск - `v0.13.0`, заметки:
[distribution/v0.13.0.md](distribution/v0.13.0.md); предыдущий -
[`v0.12.0`](https://github.com/SergeySklyarov/Kompas3D-MCP/releases/tag/v0.12.0), его заметки:
[distribution/v0.12.0.md](distribution/v0.12.0.md). Теги выпусков - версия продукта
`vMAJOR.MINOR.PATCH` ([правило](../AGENTS.md)). Обязательный объём закрывается, только когда каждое
применимое действие режима (создание, чтение, правка, перестроение, сохранение и повторное открытие,
подавление, удаление зависимостей, отрицательные проверки, проверка геометрии) подтверждено живым
прогоном.

## Приёмка выпуска 0.13.0

Обязательный объём закрыт: режимов **134/134**, зависимостей **82/82**, вердикт `COMPLETE`, открытых
нет. Функциональная приёмка идёт по файлам поставки, а не по дереву разработчика, и клиентская приёмка
проводится рабочим клиентом на той же поставке; итог записывается в заметки выпуска
([`distribution/v0.13.0.md`](distribution/v0.13.0.md)) и в паспорт поставки. Текущее состояние и
измеренные числа: [`STATUS.md`](STATUS.md); каталог операций, матрица покрытия и профили:
[`coverage/solid-v24/`](../coverage/solid-v24/).

Измерено на поставке 0.13.0: 179 файлов, 9,7 МБ, 14 прямых инструментов, 129 операций, 129 схем;
полный живой прогон (`scripts/mcp-smoke.py --all`) - **2154 PASS / 9 NAMED / 3 UNKNOWN / 0 FAIL**,
2166 строк, 35 групп; дополнительный прогон «подавить -> снять» - **46 PASS / 1 NAMED / 0 FAIL**;
клиентская приёмка рабочим MCP-клиентом - **40 строк, 40 PASS**, расхождений нет.

## Чего пока нет

- **IGES только выгружается.** `kompas_export_iges` сохраняет модель в IGES; программного ОТКРЫТИЯ
  IGES в справке v24 нет, поэтому импорта IGES не будет.
- **Прямая правка: без правки положения и скругления.** Грани сдвигаются, удаляются и
  восстанавливаются поверхностью; правки положения грани, скругления без истории, смещения
  заменяемых граней и изменения размера грани в выпуск не входят. Удаление с сохранением тела
  работает не на всякой геометрии: на бруске режим отказывает по имени.
- **Согласование операции - не для всех мутаций.** Запрет мутации поверх несогласованной операции
  опирается на документ в журнале, а у 16 мутаций аргумента `document_id` нет (строка долга 84).
- **Спецификации и прочие 2D-документы.** Чертежи профиля `drawings-minimal-v1` закрыты (виды,
  размеры, штамп, технические требования, DXF/DWG). Спецификация модели читается
  (`kompas_get_specification`), но только чтением: строки не создаются и не правятся, файл `.spw` не
  читается, часть полей строки в контракт не входит. Сборочные чертежи и остальные 2D-документы
  КОМПАС в выпуск не входят.
- **В сборках** массивы компонентов и виды сопряжений сверх профиля `mates-minimal-v1` в этот выпуск
  не входят. Состав изделия читается и выгружается (`kompas_get_bom`, `kompas_export_bom`, профиль
  `bom-minimal-v1`), но не правится: строки ведомости только читаются. Компоненты внутри подсборок
  читаются, а их размещение и файл-источник правятся: ссылка вложенного компонента несёт путь по
  `IPart7.Parts`, запись идёт маршрутом API7, а координаты вложенного - локальные, в его родителе.
  Удаление, BOM, пересечения, разнесение и массивы по-прежнему адресуют только верхний уровень.
- **Эскиз прямо на грани.** Документированный маршрут принимает опорой плоскость, поэтому грань
  отвергается по виду ссылки. Эскиз у грани строится на плоскости, созданной от неё
  (`kompas_create_aux_geometry`, `plane/offset`, `base_face_ref`), формой `plane: { reference }`.
- **Переменные детали.** Создание переменных (`kompas_create_variable`) и привязка параметров
  операций (`kompas_bind_parameter`) входят в выпуск; `kompas_set_variable` меняет значение или
  выражение существующей переменной. Удаление и переименование переменных, функциональные и
  интервальные переменные, таблица переменных, переменные компонентов сборки и привязка размеров
  эскиза - вне выпуска.
- Родные приклеивание и вырезание по траектории (`SM-04.boss`) отложены; сохранение копии базового
  объекта при объединении (`SM-15.union.mode_save_base_copy`) запланировано следующим этапом.
- Профили из таблицы выше - это не весь каталог операций P6: в каталоге **41 семейство**, из них
  **24** в обязательном объёме (**94** обязательных режима). План:
  [implementation-plan.md](../coverage/solid-v24/implementation-plan.md).
- Сервер не правит произвольную операцию КОМПАС: то, что не подтверждено, возвращается как
  `CAPABILITY_UNAVAILABLE` с объяснением, а не как успех.
